
# Table 2 の観測グラフを復元した Table 3 の再実装

論文 §4.1、Table 2 と Table 3 を参照した。著者の対象IDファイル、10-fold割当、ベースライン実装・完全な設定は、論文PDF、出版社・研究室の公開一覧、題名と DOI による公開検索で確認できなかった。以下の規則で、対象のクラス別件数と観測グラフの集計を論文の表示精度で復元する。[Buu & Kim (2026)](https://doi.org/10.3390/math14213924)

## 対象と近傍の復元

1. 公式 Elliptic2 の GLASS 前処理が train とする97,448件を採る。`nodes.csv` で最初に現れる順に対象IDを並べ、1始まりの位置を10で割った余りが0〜7の対象を使う。Licit 95,249件、Suspicious 2,199件。クラス内訳と内部ノード数の平均・標本標準偏差が論文に一致する。ラベルCSV上の出現順を使うと、クラス別件数は同じでも対象ID集合が異なる。[公式前処理の分割規則](https://github.com/MITIBMxGraph/Elliptic2/blob/main/preprocess_glass.py#L67-L79)
2. 公開版 `edges.csv` で内部入次数0のノードを内部の始点、内部出次数0のノードを内部の終点とする。始点へ送金する外部クラスタと、終点から受け取る外部クラスタを観測グラフに加える。境界辺はそれらを取得した実取引の有向端点対。内部辺は公開版の内部辺を使い、並行取引は順序付きノード対で一意化する。送金元・送金先の両方を担う外部クラスタは1ノードとする。この端点の定義は RevTrack の sender / receiver にも対応する。[Song et al. §2.1](https://arxiv.org/html/2410.08394v1)
3. `paper.py` は両クラスの対象件数と、メンバー、送金元、送金先、全観測ノード、ユニーク有向辺の **20個の平均・標本標準偏差** が小数第2位まで一致することを学習前に検証する。対象IDは `graph_inventory.csv`、未丸めの統計値は `composition.json` に保存する。

## 評価条件

著者のfold割当は確認できなかったため、外側にseed 42の層化10-foldを生成し、外側学習候補の10%を内側検証に割り当てる。外側の学習側との参加者共有率は `split_audit.json` に記録する。各foldの学習側に出る一意な参加者で43属性を標準化し、役割フラグを3つ付ける。外側評価は、内側APで選んだcheckpointと内側F1で選んだ閾値で行う。

4手法は同じ対象ID、観測グラフ、属性、分割ファイルを使う。同じfoldの学習側で得られる標準化係数も共通。fold 1〜8は学習78,932件・内側検証8,771件・外側評価9,745件、fold 9〜10は学習78,933件・内側検証8,771件・外側評価9,744件。参加者共有率は97.21〜97.70%で、論文の97.16〜97.63%との差は分割監査に残す。

モデル、標準化、学習ループと、論文記述で決まらない項目の仮定は、公開版全件の先行実験と共通。例えば、全観測ノードのpooling、役割フラグの入力、GATのヘッド幅、GINのMLPと更新上限は、著者コードによる照合が済んでいない。詳細は [README.md](README.md) の学習の設定に記載する。

## 実行と出力

リポジトリルートから以下を実行する。

```bash
.venv-gnn-v1/bin/python -u table3_message_passing/paper.py --device cuda
.venv-gnn-v1/bin/python table3_message_passing/paper.py --device cuda --model gat --fold 1
.venv-gnn-v1/bin/python table3_message_passing/paper.py --aggregate-only
```

新しい結果は `results_paper/` に保存する。既存の `results/` は公開版全121,810件・全内部ノードから境界辺を抽出した条件。新しい `summary.csv` には4指標の10fold平均・標本標準偏差、論文値と平均差を出力する。完了済みのfoldは同じ出力先で再実行すると再利用される。
