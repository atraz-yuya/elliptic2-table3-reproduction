# Elliptic2 Table 3 reproduction

This repository contains a public-data reimplementation of four message-passing baselines,
data and label audits, and a follow-up test funding holdout experiment.

- [Reproduction and handoff instructions](table3_message_passing/HANDOFF.md)
- [Experiment design](table3_message_passing/README_paper.md)
- [Data and label audit](table3_message_passing/DATA_AUDIT.md)
- [Funding holdout](table3_message_passing/README_funding_holdout.md)

The reference summaries and manifests are included. Obtain the Elliptic2 inputs from
the dataset provider and follow the handoff instructions to regenerate the caches
and model artifacts.
